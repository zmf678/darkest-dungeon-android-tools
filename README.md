# 余烬档案馆

适配 Wicked《暗黑地牢》Android 移植版 v2.2.2（`com.darkestdungeon`），支持 Android 11 及以上。应用在本地保存档案，不申请联网权限。Android 通过系统文件选择器授权访问你选的文件和文件夹。

这是独立的社区工具。本仓库提供档案馆源码和自动存档补丁，构建游戏实验版需要在本机提供兼容的 APK。

## 存档版本与回档

完整保存后自动留档的实验版搭配方式见 [游戏补丁与实验版](game-patch/README.md)。下面的手动流程适用于原版及已有导出。

1. 在游戏中选择 **存档与模组 → 存档 → 导出**，把存档导出到一个普通文件夹。
2. 在档案馆选择 **建立存档版本**，导入游戏生成的文件夹，或导入包含 `profile_0` 至 `profile_8` 的 ZIP。单独的档位文件夹也可导入。
3. 可给版本重命名，并查看每个档位和上一份备份相比是否变化。存档版本保留原始档位文件字节，ZIP 可另存到设备上。
4. 点开历史版本并选择 **回档到此版本**，选一个或全部档位。首次选择回档文件夹，之后会复用该目录。在游戏中用 **存档 → 导入** 选择档案馆生成的文件夹及目标档位。回档前可再建立一个版本保留目前进度。

原版的存档目录由游戏自身读写。档案馆通过导入管理原版的检查点。

## 模组

- 可收录带 `project.xml` 的 ZIP，也识别常见旧版模组目录。档案馆会保留原始 ZIP。
- 连接 `Android/media/com.darkestdungeon/mods` 可查看游戏目录中的模组并把它们备份到库中。
- 把选中的 ZIP 导出后，可从游戏的模组菜单导入。材质转换、启用状态和加载顺序由游戏处理。

## 构建

使用 JDK 17 或以上、Android SDK 36 和兼容 AGP 9.3.1 的 Gradle 9.5。在项目根目录运行 `gradle :app:assembleDebug :app:lintDebug`。

原创插画及字体来源见 [DESIGN.md](DESIGN.md)，字体许可证随 APK 提供。
